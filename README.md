# EX-02: Cross-Platform Prompting: Evaluating Diverse Techniques in AI-Powered Text Summarization & Prompt Engineering

## AIM
To evaluate and compare the effectiveness of prompting techniques (zero-shot, few-shot, chain-of-thought, role-based) across different AI platforms (e.g., ChatGPT, Claude, Gemini/Bard, Cohere Command, and Meta) across a variety of specific tasks including text summarization, reasoning, and context processing.

---

## ALGORITHM

1. **Define the Use Case:** Select specific tasks for evaluation across platforms (e.g., summarizing a document, answering a technical question, or generating a comparative analysis). Ensure the use case is applicable to all platforms and allows for comparison across response quality, accuracy, and depth.
2. **Create a Set of Prompts:** Prepare a uniform set of prompts aligning with the chosen use case. Each prompt should be clear and precise, ensuring all platforms are evaluated using identical inputs. Include multiple prompt types (straightforward, tabular, comparative, context-dependent) to capture the versatility of each platform.
3. **Run the Experiment on Each AI Platform:** Input the prompts into each AI tool (ChatGPT, Claude, Gemini/Bard, Cohere Command, and Meta) and gather the responses. Ensure identical testing conditions across platforms. Record response times, ease of interaction, and any technical constraints encountered.
4. **Evaluate Response Quality:** Assess each platform’s responses using four core criteria:
   * **Accuracy:** Correctness of the generated information.
   * **Clarity:** Readability, structure, and coherence.
   * **Depth:** Thoroughness and detail provided in the response.
   * **Relevance:** How directly the output addresses the prompt.
5. **Compare Performance:** Analyze collected outputs to identify differences across platforms and document platform-specific advantages.
6. **Deliver Results:** Compile a comparison matrix outlining platform performance and generate a final summary report detailing recommendations for practical use cases.
